# 电商零售：业务健康度与用户价值分析

基于 UCI Online Retail 数据集（541,909 条逐行订单明细），完成一次完整的电商业务健康度 + 用户价值分析。

## 数据来源

- **数据集名称：** Online Retail II (UCI Machine Learning Repository)
- **下载地址：** https://archive.ics.uci.edu/static/public/352/online+retail.zip
- **格式：** Excel (.xlsx)，单个工作表，541,909 行 × 8 列
- **时间范围：** 2010年12月 - 2011年12月
- **涵盖国家：** 38 个国家/地区

## 分析内容

| 章节 | 内容 |
|------|------|
| 1. 数据字典 | 8 个字段的含义、粒度、业务推断 |
| 2. 数据质量审计 | 缺失率、异常值、重复记录、清洗规则清单 |
| 3. 核心指标看板 | 月度 GMV、订单数、客单价、活跃用户、复购率、取消率 |
| 4. RFM 用户分群 | 9 个分群（冠军客户、忠诚客户、风险客户等） |
| 5. LTV 分析 | 按队列的客户累计生命周期价值 + 留存率 |
| 6. 异常检测 | GMV 异常波动识别（IQR + Z-Score） |
| 7. 行动建议 | 5 条可执行建议，含预期收益和实验设计 |
