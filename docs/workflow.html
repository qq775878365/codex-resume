本工作流体系围绕团购品牌营销的核心环节，设计了3条自动化流水线，覆盖从情报采集、内容生产到竞品监控的全链路。

│             │              │                    │

二、工作流详情

工作流1：团购行业每日情报（自动化）

属性 说明
触发频率 每天早上9:00
执行工具 WorkBuddy Agent（WebSearch + AI分析）
数据源 百度新闻、行业媒体、社交平台、官方公告
输出 3-5条精选行业动态 + 1条趋势洞察

工作流程：

定时触发(9:00AM)
  → WebSearch搜索"团购"关键词组
  → WebFetch抓取重点文章详情
  → AI分类整理（平台动态/市场趋势/营销案例/技术工具/政策法规）
  → 提炼3-5条核心动态
  → 生成今日洞察
  → 输出结构化日报

Prompt模板：

搜索今日中国团购行业最新动态，包括：
1. 美团、抖音团购、小红书团购等平台的最新新闻和政策变化
2. 本地生活服务领域的重要事件
3. 团购营销相关的新工具、新方法、新案例

输出格式：
📰 团购行业每日情报 | {日期}
1. 【平台动态】xxx
2. 【市场趋势】xxx
3. 【营销案例】xxx
4. 【技术工具】xxx
5. 【政策法规】xxx
💡 今日洞察：xxx

效率对比： | 指标 | 人工执行 | AI自动化 | |------|---------|---------| | 耗时 | 60-90分钟/天 | 3-5分钟/天 | | 覆盖面 | 3-5个信息源 | 20+个信息源 | | 输出质量 | 依赖个人经验 | 结构化、可追溯 | | 效率提升 | - | 95%+ |

工作流2：周度内容排期生成（自动化）

属性 说明
触发频率 每周日晚上20:00
执行工具 WorkBuddy Agent（WebSearch + AI规划）
数据源 行业热点、平台趋势、用户行为数据
输出 4平台×3条选题 = 12条内容 + 内容日历

工作流程：

定时触发(周日20:00)
  → WebSearch搜索本周团购热点
  → AI分析热点与平台匹配度
  → 为4个平台各生成3条选题
  → 每条选题含：标题/方向/时间/效果预估
  → 生成本周内容日历总览
  → 输出结构化排期表

多平台适配策略： | 平台 | 内容形式 | 时长/篇幅 | 发布高峰 | 调性 | |------|---------|----------|---------|------| | 抖音 | 短视频/直播 | 15-60秒 | 12:00/18:00/21:00 | 活泼、有节奏感 | | 小红书 | 图文笔记 | 300-800字 | 12:00/20:00 | 精致、有种草感 | | 美团 | 店铺营销 | 活动描述 | 10:00/17:00 | 实惠、直击痛点 | | 微信 | 朋友圈/社群 | 100-300字 | 08:00/12:00/20:00 | 真实、有温度 |

效率对比： | 指标 | 人工执行 | AI自动化 | |------|---------|---------| | 耗时 | 3-4小时/周 | 10-15分钟/周 | | 选题数量 | 6-8条 | 12条 | | 平台覆盖 | 2-3个平台 | 4个平台全覆盖 | | 效率提升 | - | 90%+ |

工作流3：竞品动态周报（自动化）

属性 说明
触发频率 每周一早上9:00

四、Prompt工程规范

4.1 Prompt设计原则

原则 说明 示例
角色设定 明确AI扮演的角色 "你是一位资深团购营销分析师"
任务明确 清晰描述输出要求 "输出3-5条行业动态，每条一句话概括"
格式约束 指定输出结构 "使用Markdown表格，包含平台/事件/影响三列"
质量标准 定义什么是好结果 "信息必须附带来源URL，数据需标注时间"
迭代优化 根据结果调整Prompt 增加约束条件、调整分类维度

4.2 常用Prompt模板库

模板1：行业新闻摘要

角色：团购行业分析师
任务：搜索并整理今日行业动态
约束：
- 至少覆盖3个平台（美团/抖音/小红书）
- 每条动态附带信息来源
- 区分"事实"和"观点"
输出：结构化日报，含趋势洞察

模板2：竞品分析报告

角色：竞品分析专家
任务：分析{平台名}本周重大变化
约束：
- 与上周对比，标注变化点
- 分析对中小商家的影响
- 给出可落地的应对建议
输出：对比表格+洞察+建议

模板3：内容选题生成

角色：内容策划总监
任务：为{平台名}生成本周内容选题
约束：
- 选题必须与当前热点关联
- 每条选题包含标题+方向+发布时间
- 调性符合平台用户偏好
输出：选题表格，含内容日历

七、总结

本工作流体系的核心价值：

  1. 降本增效：将每周12小时的重复性工作压缩到45分钟，效率提升94%+
  2. 标准化输出：确保情报采集、内容排期、竞品监控的质量一致性
  3. 可扩展性强：基于WorkBuddy Agent的自动化框架，随时可以增加新的工作流
  4. 实战验证：3条工作流已在WorkBuddy上实际搭建并运行
