团购行业每日情报 | 2026年6月1日

📰 行业动态摘要

1. 【政策法规】

《网络餐饮服务经营者落实食品安全主体责任监督管理规定》6月1日起施行，美团、淘宝闪购、京东三大平台接受联合行政指导，反垄断调查同步进行。

来源：市场监管总局、北京/上海市场监管局联合行政指导会

2. 【市场趋势】

外卖补贴大战降温，美团与淘宝闪购订单比例回落至58%对42%，竞争升级为本地生活生态入口争夺战，抖音、淘宝、京东、高德等多平台涌入本地团购新战场。

来源：36氪分析

3. 【营销案例】

小红书以"66周年庆"为主题打造618大促（5月22日至6月18日），提出"好货主场"策略，重点扶持店播并为商家提供转化型笔记和蓄水型笔记两条激励赛道。

来源：网经社报道

4. 【技术工具】

抖音团购推出独立App"抖省省"，上线3个月日活近1600万，通过算法推荐和独立交易工具提升核销率，与大众点评用户重合度不足30%。

来源：36氪报道

5. 【平台动态】

上海家电数码以旧换新补贴6月1日起调整为线上即时摇号，优化消费者体验；红旗连锁启动"唤醒夏日"系列促销活动。

来源：百度百家号、同花顺财经

💡 今日洞察

本地生活服务竞争进入新规时代，平台需在合规基础上通过独立App、生态融合、场景创新等多维度竞争，谁能更高效地连接"内容激发"与"线下核销"将成为关键。

📊 执行总结

核心动态： 1. 政策环境变化：6月1日起施行的外卖新规标志着监管进入新阶段，平台需在合规基础上运营 2. 竞争格局升级：从单纯外卖补贴战转向本地生活生态入口争夺，多平台涌入团购战场 3. 营销策略创新：小红书"好货主场"策略和抖音独立App代表两种不同的竞争路径 4. 技术工具演进：独立App、算法推荐、场景创新成为提升核销效率的关键

市场趋势： - 外卖大战降温后，本地团购成为新焦土战场 - 竞争焦点从消费者补贴转向商家端BD拉锯战 - 用户需求从"确定性搜索"向"随机性激发"转移 - 平台需平衡内容生态与交易效率的关系
